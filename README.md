# Logistics Data Analytics Internship

This repository contains my weekly tasks and practical work completed as part of a Logistics Data Analytics Internship.

## About the Project

The internship focuses on applying data analytics and data science techniques to logistics and supply chain problems.

The project covers:

- Strategic planning
- Data collection
- Data cleaning
- Data preprocessing
- Exploratory Data Analysis
- Data visualization
- KPI analysis
- Statistical analysis
- Machine learning
- Business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Power BI
- Git & GitHub
